# МебельПро — Flutter MVP

Кроссплатформенный стартовый проект для Android и Windows.

## Что уже есть
- Адаптивная навигация для телефона и широкого экрана.
- Разделы «Проекты», «Конструктор», «Материалы», «Раскрой».
- Ввод габаритов корпуса и толщины ЛДСП.
- Предварительный расчёт базовых деталей корпуса.
- Зафиксированные исходные настройки: лист 2800×2070 мм, ЛДСП 16 мм, пропил 4 мм, кромка 0,4/2 мм.

## Важно
Это ранний MVP-каркас, а не готовая производственная CAD/CAM-система.
Расчёт ящиков, фасадных зазоров, фурнитуры, кромления, 3D и оптимизатор раскроя ещё предстоит реализовать и проверить на контрольных примерах. Не используйте текущий предварительный список деталей для заказа распила.

## Запуск
Установите Flutter SDK и Android Studio (для Android) либо Visual Studio с workload «Desktop development with C++» (для Windows).

В каталоге проекта выполните:

```bash
flutter pub get
flutter run
```

Android APK:

```bash
flutter build apk --release
```

Windows:

```bash
flutter build windows --release
```

## Следующий этап
1. Уточнить конструктив корпуса: накладные/вкладные боковины, верх/дно между боковинами или накладные.
2. Реализовать корректные формулы ящиков под выбранные типы направляющих.
3. Добавить редактируемые параметры листа, пропила, текстуры и кромки.
4. Реализовать проверенный прямоугольный nesting-алгоритм и визуальную карту раскроя.
5. Добавить 3D-сцену, фурнитуру, смету и экспорт.
